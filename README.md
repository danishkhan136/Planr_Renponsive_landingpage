**Planr** is a modern, dark-themed, and fully responsive SaaS landing page designed for a project management platform.  
It is built using **HTML5**, **CSS3**, **Bootstrap 5**, **Swiper.js**, **Google Fonts**, and custom SVG assets.

The design focuses on a professional digital-agency style layout with a strong hero section, trusted agency logos, feature highlights, client testimonials, pricing cards, FAQ accordion, call-to-action section, and a complete footer.

## About the Project

**Planr Responsive Landing Page** is a front-end web design project created to practice professional landing page development, responsive layouts, UI section building, and modern website styling.

The project represents a project management SaaS website for digital agencies. It presents the product in a clean and attractive way by using a dark user interface, elegant typography, pricing plans, testimonials, and conversion-focused call-to-action buttons.

This project is suitable for a portfolio because it demonstrates real-world frontend skills such as HTML structure, Bootstrap layout, responsive CSS, reusable sections, and modern UI presentation.

## Website Sections

### 1. Navbar

The navbar contains the main navigation links such as **About Us**, **Pricing**, **Blogs**, and **Pages**. It also includes a strong call-to-action button for buying or accessing the template. The navbar is designed to work across different screen sizes.

### 2. Hero Section

The hero section introduces the product with a strong headline:

> Effortless Project Management for Digital Agencies

It includes a short product description, an update badge, active user highlight, and a primary call-to-action button. This section is designed to quickly explain the product value and attract user attention.

### 3. Trusted Agencies Section

This section displays trusted brand or agency logos to build credibility. It helps make the landing page feel more professional and suitable for a SaaS product.

### 4. Features Section

The features section explains how the platform helps users manage projects more efficiently. It highlights important benefits such as:

- Real-time collaboration
- Customizable workflows
- Visual task management
- Seamless canvas board experience

### 5. Testimonials Section

This section uses **Swiper.js** to display feedback from clients in a slider format. It adds social proof and improves the professional look of the landing page.

### 6. Projects Section

The projects section explains how users can unlock the full potential of their projects. It presents features such as collaboration, analytics, time tracking, automated notifications, and visual project management.

### 7. Pricing Section

The pricing section includes three plans:

| Plan | Price | Best For |
|---|---:|---|
| Starter | Free | Individuals and small teams getting started |
| Teams | $45 / user yearly | Growing teams needing advanced features |
| Business | $90 / user yearly | Large agencies requiring premium tools and support |

This section helps users compare available options and choose the plan that fits their needs.

### 8. FAQ Section

The FAQ section answers common questions about the free plan, upgrades, trial system, payment methods, data security, support, cancellation, and integrations.

### 9. Call-to-Action Section

The CTA section encourages users to start using the platform and experience the benefits of improved project management.

### 10. Footer

The footer includes page links, utility links, social media links, copyright information, and policy links. It gives the website a complete and professional ending.

## How to Run the Project

This is a static frontend project, so you do not need to install any packages or run a backend server.

### Option 1: Open Directly in Browser

1. Download or clone the repository.
2. Open the project folder.
3. Double-click the `index.html` file.
4. The landing page will open in your browser.

### Option 2: Run with VS Code Live Server

1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.
5. The project will run locally in your browser.
